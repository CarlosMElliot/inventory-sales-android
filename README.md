# Inventory & Sales — Web Application

A responsive inventory and sales application for U.S. small businesses. One subscription covers one business and one business user; the creator manages accounts separately.

**Current platform: web-first. Native Android is deferred.** The repository name is historical.

## Status and constraints

Documentation and design references are available. They do not establish a working web app or production backend. See progress for the latest evidence.

Preserve orders, invoices, credits, payment records, customers, products, inventory, signatures, printing/PDF/email/sharing, complete history, comparisons, backups and offline synchronization. Build in stages without silently dropping requirements.

Start on free services. Never commit secrets. Paid upgrades and production publishing require owner authorization. Historical Android instructions are superseded by WEB_APP_SPEC.md.
